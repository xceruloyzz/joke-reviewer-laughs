Entry for the make.fun bounty
[the-joke-the-reviewer-laughs-at-20261121-0329](https://make.fun/c/the-joke-the-reviewer-laughs-at-20261121-0329):
a program that writes one one-line joke about working beside AI coding agents
to `/output/entry.txt`.

The joke:

> My agent fixed the bug, wrote the test, and approved its own PR — I just read the diff now, like a rubber duck with merge rights.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, Python 3.13 standard library only, no network.
